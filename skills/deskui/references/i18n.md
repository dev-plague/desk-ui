# i18n en DeskUI

DeskUI tiene dos capas de internacionalización:

1. **Textos internos de los componentes** (`DeskUILocaleProvider`).
2. **Documentación del proyecto**, con diccionarios `es`/`en` y `?lang=en`.

Esta referencia cubre la primera. Para la segunda, mira
`apps/docs/src/i18n/` en el monorepo.

## Proveedor

```tsx
import { DeskUILocaleProvider } from "@deskui/ui";

export function Root() {
  return (
    <DeskUILocaleProvider locale="en">
      <App />
    </DeskUILocaleProvider>
  );
}
```

En un consumidor con el CLI, el archivo copiado es `@/lib/i18n`:

```tsx
import { DeskUILocaleProvider } from "@/lib/i18n";
```

Sin proveedor, el idioma por defecto es **español**. Esto conserva el
comportamiento de versiones anteriores.

## Sobrescrituras parciales

```tsx
<DeskUILocaleProvider
  locale="en"
  messages={{
    pagination: { next: "Forward" },
    notepad: { untitled: "New document" },
  }}
>
  <App />
</DeskUILocaleProvider>
```

Las secciones son planas: `common`, `desktop`, `pagination`, `wizard`,
`properties`, `notepad`, `fileExplorer`, `minesweeper`, `blueScreen`,
`screensaver`, `terminal`, `toast` y `scrollArea`.

## Componentes con textos internos

- `Pagination`
- `Wizard`
- `PropertiesDialog`
- `Notepad`
- `FileExplorer`
- `Minesweeper`
- `Terminal`
- `BlueScreen`
- `Screensaver`
- `TitleBar`
- `Toast`
- `ScrollArea`
- `Desktop`

Las props explícitas (`okLabel`, `backLabel`, `restartLabel`, etc.) siguen
teniendo prioridad sobre el diccionario.

## Añadir un idioma nuevo

1. Copia la interfaz `DeskUIMessages` y el diccionario de
   `packages/ui/src/lib/i18n.tsx`.
2. Añade el idioma a `DeskUILocale` y a `DESKUI_LOCALE_MESSAGES`.
3. Traduce todas las secciones; TypeScript obliga a mantener la forma.
4. Añade un test que renderice `Pagination` o `TitleBar` con el nuevo locale.
5. Actualiza el registry si el archivo `lib/i18n.tsx` cambia de forma.

## Textos de demo

Los textos de ejemplo del Page Builder y de los showcases son contenido de
demostración. El chrome, las etiquetas de bloque y los textos de accesibilidad
sí se traducen. Si un proyecto necesita otro idioma, debe traducir su propio
contenido además de usar el proveedor.

## Accesibilidad

Traduce también:

- `aria-label` y `aria-labelledby`.
- `title` y `placeholder`.
- Textos `sr-only`.
- Nombres accesibles de botones que solo muestran un icono.
- Mensajes de estado y errores.

El idioma del documento (`<html lang>`) es responsabilidad de la aplicación;
DeskUI no lo modifica.
